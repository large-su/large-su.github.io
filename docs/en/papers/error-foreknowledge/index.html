Journal of Manufacturing Systems · 2023 · Co-author

Feature fusion and distillation embedded sparse Bayesian learning model for in-situ foreknowledge of robotic machining errors

面向机器人加工误差在位预测的稀疏贝叶斯模型：特征融合与蒸馏

Shengqiang Zhao, Hao Sun, Fangyu Peng, Rong Yan, Xiaowei Tang, Yunan Shan, Juntong Su

Publisher’s version↗

Abstract summary

Process parameters, robot stiffness, and cutting loads together affect robotic machining errors. The study fuses and distills static and dynamic features for a sparse Bayesian in-situ predictor. Its performance is evaluated on curved specimens shaped like marine propeller blades.

Key contributions

  • A sparse Bayesian foreknowledge framework combines feature fusion with distillation for robotic machining error.
  • Process parameters, robot stiffness, and multidomain force features are fused in a structured order across static and dynamic information.
  • Machining data from blade-shaped specimens are used to evaluate in-situ prediction.
