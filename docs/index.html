机器人加工与运动规划

关于我

你好，我是苏俊通，在华中科技大学机械科学与工程学院做机器人加工研究。拿螺旋桨来说，相邻桨叶留给刀具的空间很有限。机器人只是换个姿态，刀具能不能到达、加工表面会是什么样，都可能跟着变。

我想弄清楚，力、振动等信号能告诉我们多少加工现场的情况，以及有多种约束时，怎样让机器人沿着刀路走得顺。这两个问题把我在加工感知和姿态运动规划上的工作串在了一起。

这个主页记录了我和合作者围绕这些问题做过的工作。如果你也对机器人加工或复杂曲面制造感兴趣，欢迎交流。

研究方向

  • 多约束姿态运动规划

    沿既定刀路规划连续的刀具姿态和机器人运动，兼顾可达性、避碰、运动学限制与工艺要求。

  • 多模态加工性能感知

    融合多源测量信号与加工机理模型，估计加工过程中的变形、误差和刀具磨损。

  • 受限空间机器人铣削

    以螺旋桨等复杂曲面零件为主要应用对象，借助仿真基准与加工实验研究受限空间中的可达性、姿态调整与加工性能。
