受限空间机器人铣削的三维姿态规划研究：一种势网络架构

Investigation of the 3D-posture planning for space-restricted robotic milling: A potential network architecture

Juntong Su, Shengqiang Zhao, Fangyu Peng, Xiaowei Tang, Rong Yan

出版方原文↗查看基准仓库↗

摘要概述

本文面向受限空间内的机器人铣削姿态规划问题，提出一种可扩展的势网络架构，将可达性、碰撞风险和加工性能等异构约束与目标统一映射到规划空间。研究进一步构建考虑刀具—工件接触状态的姿态流形，使工具姿态能够沿复杂曲面刀路连续调整，并通过受限空间基准任务和螺旋桨加工任务验证规划结果。

主要贡献

  • 提出由势单元、势函数、势网络和势解组成的模块化规划架构，用于统一组织多约束、多目标问题。
  • 构建与刀具—工件接触状态相关的姿态流形，为复杂曲面加工中的三维姿态描述和快速模式切换提供参数化表达。
  • 在受限空间基准和代表性螺旋桨构型上验证规划方法的可行性与适应性。
